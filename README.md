# SGO Vision para Android

Aplicativo para óticas ativas no sistema **SGO Vision**: demonstração de lentes e tratamentos, medidas, orçamentos, tabela interativa, testes visuais e catálogos de fabricantes.

- **Download e passo a passo:** https://sgo.sgovision.com.br/baixar-app
- O aplicativo só funciona depois de ativado pelo administrador da ótica (QR de acesso gerado no SGO Vision).
- Os arquivos ficam em [Releases](../../releases). Confira o SHA-256 em `SHA256SUMS.txt`.

Este repositório guarda apenas os instaladores publicados.
